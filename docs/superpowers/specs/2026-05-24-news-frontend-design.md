# 新闻数据库前端服务设计

## 概述

创建一个 FastAPI Web 服务，提供可视化界面浏览和筛选 `data/news.db` 中的新闻数据。

## 技术栈

- **后端：** FastAPI（Python）
- **前端：** 纯 HTML + JavaScript（无框架依赖）
- **数据库：** 直接读取 `data/news.db`（SQLite）
- **端口：** `5173`

## API 设计

### `GET /api/news`

获取新闻列表，支持筛选和分页。

**查询参数：**
| 参数 | 类型 | 说明 |
|------|------|------|
| `category` | string | 按分类筛选 |
| `source` | string | 按来源筛选 |
| `start_date` | string | 开始日期（YYYY-MM-DD） |
| `end_date` | string | 结束日期（YYYY-MM-DD） |
| `page` | int | 页码，默认 1 |
| `page_size` | int | 每页数量，默认 12 |

**响应：**
```json
{
  "items": [
    {
      "id": 1,
      "title": "新闻标题",
      "time": "2026-05-24",
      "source": "来源",
      "url": "https://...",
      "content": "内容摘要",
      "category": "分类",
      "analysis_report": "分析报告内容",
      "created_at": "2026-05-24T10:00:00"
    }
  ],
  "total": 100,
  "page": 1,
  "page_size": 12
}
```

### `GET /api/stats`

获取统计信息。

**响应：**
```json
{
  "total": 100,
  "categories": {"科技": 30, "财经": 20, ...},
  "sources": {"新浪": 50, "腾讯": 30, ...}
}
```

### `GET /`

返回前端页面。

## 页面结构

```
┌─────────────────────────────────────────────┐
│  [Logo] 新闻数据库    [统计概览]            │
├─────────────────────────────────────────────┤
│  [分类▼] [来源▼] [时间范围] [重置]          │
├─────────────────────────────────────────────┤
│  ┌────────┐ ┌────────┐ ┌────────┐           │
│  │ 卡片1  │ │ 卡片2  │ │ 卡片3  │           │
│  └────────┘ └────────┘ └────────┘           │
│  ┌────────┐ ┌────────┐ ┌────────┐           │
│  │ 卡片4  │ │ 卡片5  │ │ 卡片6  │           │
│  └────────┘ └────────┘ └────────┘           │
├─────────────────────────────────────────────┤
│         [< 1 2 3 ... >]                     │
└─────────────────────────────────────────────┘
```

- **顶部横条：** Logo + 标题 + 统计概览（总数、分类数）
- **筛选栏：** 分类下拉、来源下拉、日期范围、重置按钮
- **卡片网格：** 3列布局，展示标题、时间、来源、分类标签
- **详情弹窗：** 点击卡片弹出 Modal，显示完整内容和分析报告
- **分页：** 底部居中分页控件

## 数据关联

`raw_news` 联合 `classified_news` 显示，未分类的新闻也保留显示（category 字段为空）。
